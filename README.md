# Simple Interest Calculator

A lightweight Bash-based command-line tool that calculates simple interest
from user-provided inputs: principal amount, rate of interest, and time
period.

## Project Name
**simple-interest-calculator**

## Description
This project is a beginner-friendly open-source repository created to
demonstrate a complete GitHub project structure, including licensing,
contribution guidelines, a code of conduct, and a working Bash script.

## Features
- Takes principal, rate of interest, and time period as input
- Calculates simple interest using the formula: `SI = (P × R × T) / 100`
- Displays the total amount (principal + interest)

## Usage
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
